# Sheaft v1.1.0

`v1.1.0` is a minor Sheaft release for fixed-fraction experiment reproduction on the stable Bering `1.3.0` contract line.

The release remains within the v1 release-claim boundary documented in [docs/v1-major-semantics.md](../docs/v1-major-semantics.md).

## Added

- `sampling_mode: fixed_k_replica_slots`
- derived `fixed_k_failures = ceil(failure_probability * total_replica_slots)` when `fixed_k_failures` is omitted
- support for the new mode in both legacy model analysis and path-aware Bering artifact analysis
- documentation and examples for the new sampling mode

## Compatibility

This release does not change the accepted Bering contracts:

- `io.mb3r.bering.model@1.3.0`
- `io.mb3r.bering.snapshot@1.3.0`

## Notes

`fixed_k_replica_slots` is intended for reproducing experiments that fail a fixed number of replica/container slots per trial. For the product-baseline stochastic connectivity model, keep using `independent_replica`.
