# Sheaft v1.3.2

This patch is reserved for the Bering `v1.1.0` app/package compatibility
checkpoint. Bering model and snapshot schema `1.3.0` pins remain unchanged.

## Release gate

Do not publish this release or record Bering `v1.1.0` in
`tested_bering_app_versions` until the published Bering release manifest and
contracts archive pass `scripts/ci/check-bering-app-compatibility.sh`.

The check verifies the Bering app version and tag, contracts archive digest,
strict model/snapshot contract metadata, canonical fixture hashes, and actual
Sheaft consumption of both fixture artifacts. A source checkout, draft release,
or locally assembled package is insufficient for the tested-version claim.

After that gate passes, update the compatibility generator, regenerate
`compatibility-manifest.json`, replace this gate text with the verified release
checkpoint, and run the normal Sheaft release validation.
