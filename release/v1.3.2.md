# Sheaft v1.3.2

`v1.3.2` records verified app/package compatibility with the published Bering
`v1.1.0` release. Bering model and snapshot schema `1.3.0` pins remain unchanged.

## Changes

- Added a fail-closed published-app compatibility checker.
- Added that checker to the release dry-run, deriving the Bering tag from the
  generated compatibility manifest and downloading the exact public assets.
- Updated `tested_bering_app_versions` to `v1.1.0` after the published assets
  passed the check.

## Verified upstream checkpoint

The check used Bering tag `v1.1.0` at commit
`4f39af04f38e71f8c215a434adc3e3847ad86f21`. The published contracts archive
digest is
`sha256:8c1b981f950a497f0005b237f5494c43c2ec8196b3260612b09c4dfaad8fb57f`.

The gate verifies the Bering app version and tag, contracts archive digest,
strict model/snapshot contract metadata, canonical fixture hashes, and actual
Sheaft consumption of both packaged fixture artifacts. A source checkout, draft
release, or locally assembled package is insufficient for this tested-version
claim.

## Compatibility

Accepted upstream contracts remain exactly
`io.mb3r.bering.model@1.3.0` and
`io.mb3r.bering.snapshot@1.3.0`, with their existing pinned URIs and digests.
There is no parser fallback or schema widening in this patch.
